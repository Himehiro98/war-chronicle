# WAR CHRONICLE 全体レビューと改修方針（2026-10）

## 1. レビューで見つかった問題

### 設計・UI
| # | 問題 | 影響 |
|---|------|------|
| D1 | **全ページが独自ヘッダー**を持ち、ナビ項目もページごとにバラバラ（トップは15項目フラット、「パターン」系が2つ、絵文字の重複）。共通レイアウトが無い | 迷子になる・どこに何があるか分からない |
| D2 | `html { zoom: 1.25 }` で全体を拡大し、その前提で文字が 9〜12px で組まれている。地球儀はこれを打ち消す hack が必要になっている | 小さい文字・WebGL座標ズレ・保守困難 |
| D3 | 見た目の方向性が混在（羊皮紙セピア／ネイビー／ページごとに違うグラデーション）。カード見出しが全部違う原色で、情報の優先度が見えない | 雑然として見える・読み疲れ |
| D4 | 日本語フォント未指定（Playfair / Source Serif は欧文のみ）→ OS任せの明朝/ゴシック | 端末で見た目がブレる |
| D5 | ホバー効果を JS（onMouseEnter）で書いている、フォーカス表示なし | キーボード操作・アクセシビリティ |

### UX・構造
| # | 問題 | 影響 |
|---|------|------|
| U1 | **戦争ごとのページ（URL）が無い**。詳細は `/explore?war=…` のクライアント描画のドロワー | 共有・ブックマーク・検索エンジンに弱い。戦争間移動でタブ状態が残る |
| U2 | 約1MBの本文データ（content.ts）を探索ページ等のクライアントJSに丸ごと同梱 | 初回表示が重い（特にスマホ） |
| U3 | トップの入口が多すぎて「最初に何をすればいいか」が弱い（CTA 4つ＋ナビ15） | 初見ユーザーの離脱 |
| U4 | 戦争詳細に「前後の戦争へ」移動や現在地（パンくず）が無い | 回遊しにくい |
| U5 | 各ページの metadata（タイトル）が全部同じ、sitemap も無い | SEO・タブで区別できない |

### 記載内容
| # | 問題 |
|---|------|
| C1 | **戦争数の表記がバラバラ**：100以上 / 167 / 175 / 176（実データは176件） |
| C2 | **ライブページの「最終更新」が偽装状態**：GitHub Actions が毎週日付だけ書き換えており、中身（死者数・動向）は2025年時点のまま。2026-10-19更新と表示されるが実態は約1年前のデータ |
| C3 | 構造分析タブの「主要因子の影響度分析」バーが**全因子75%固定**のダミー |
| C4 | 教訓一覧の「再現性：高/中/低」統計が本文のキーワード拾いで、ほとんどが未分類（中0・低0）＝誤解を招く数字 |
| C5 | 宗教カード・宗教ページで `<strong>` タグが生のまま表示される |
| C6 | 学習パスの中身のズレ：「冷戦ルート」にフォークランド紛争・ボスニア紛争（冷戦の代理戦争ではない）、「6つのパターン」の説明と収録戦争が不一致 |
| C7 | 「準備中だワン」等のプレースホルダー文言が方言混在（ワン／ばい／やけん／ちょって） |

## 2. 改修方針

1. **基盤**：デザイントークン（CSS変数）、Noto Sans JP / Noto Serif JP、zoom hack撤去と文字サイズ是正、共通ヘッダー（5グループのナビ＋スマホ用メニュー）とフッター
2. **戦争ページ化**：`/wars/[id]` を静的生成。本文はサーバー側で描画し、クライアントJSから content.ts を外す。旧URL `/explore?war=…` は自動転送。タブはURLハッシュ連動、前後の戦争・パンくず付き
3. **トップ再設計**：「はじめて → 通史」「目的から → 学習パス／現代の問い」「自由に → 年表・地図」の3導線に整理。数値はデータから自動計算
4. **内容の是正**：C1〜C7 をすべて修正。ライブデータは2026年10月時点の情報で更新し、日付だけ書き換えるワークフローを廃止
5. **各ページの磨き込み**：通史・パターン・因果・教訓・検索・学習パス・テーマ・宗教・わんた・フラッシュカード・診断系・ライブを共通デザインに統一
6. **SEO**：ページ別タイトル、sitemap / robots
7. **QA**：build、スマホ表示、全ページ確認、master 取り込み

ナビゲーションのグループ：
- **読む**：通史 / 学習パス / 現代の問い / 宗教から読む
- **探す**：年表・地図 / 戦争一覧 / 全文検索
- **構造を見る**：パターン進化 / 因果の大河 / 教訓
- **試す**：フラッシュカード / AI診断 / 構造リスク診断 / わんたの解説
- **いま**：進行中の戦争
